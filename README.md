# iftekharzeeon.github.io

Personal site of Iftekhar E Mahbub Zeeon. Astro, static output, deployed to GitHub Pages by
`.github/workflows/deploy.yml`.

- Run locally: `pnpm install`, then `pnpm dev`.
- Build: `pnpm build` writes the site to `dist/`.
- Content: case studies in `src/content/work/`, notes in `src/content/notes/`, the home page in
  `src/pages/index.astro`.
- Every number on the site must have a source. The plan and the source list are in Zeeon's
  control repo: `specs/portfolio/001-portfolio-plan.md`.
